# platojobs.github.io

Personal GitHub Pages site for `platojobs`.

## Stack

- HTML
- CSS
- JavaScript

## Features

- Editorial-style landing page
- Responsive layout for desktop and mobile
- Live public repository cards loaded from the GitHub API
- Zero-build deployment on GitHub Pages

## Local preview

```bash
python3 -m http.server 4173
```

Then open:

```text
http://127.0.0.1:4173
```
